# Daniel Benítez

**Software developer focused on large-scale web scraping and AI integration.**
Technical lead building agentic systems with local LLMs and MCP, scraping platforms in Python and JavaScript, and the core infrastructure behind them. Based in Andalusia, Spain. Open to remote, hybrid or on-site.

## What I do

- **Scraping at scale.** Selenium, Playwright and Camoufox pipelines with proxy rotation and CAPTCHA handling, built to fail fast, diagnose their own blocks and report honestly when a source is down.
- **AI integration.** Multi-agent systems with local LLMs (Qwen, Ollama), MCP servers, and automated scraper auditing and repair with Claude Code.
- **Platform and infrastructure.** FastAPI service hubs, Linux servers on Hetzner and AWS, GitHub Actions, Celery, and corporate SSO with Authentik and Keycloak.
- **Engineering process.** Scrum, TDD and Organic Driven Development; GitHub governance with Actions and git hooks.

## Results

- Consolidated 35 AWS servers into a single Hetzner host with a custom scheduler: **-85% infrastructure cost** and a **96% scraper success rate**.
- Replaced 18 UiPath bots on Windows Server with an in-house RPA on Ubuntu: **about EUR 50,000 per year saved** (estimate).
- Rolled out SSO across all core applications and cut production incidents to near zero through review and automation practices.
- Earlier: perception and control software for a driverless vehicle (Python, C++, LIDAR 3D mapping) with ARUS, University of Seville.
